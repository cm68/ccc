# Active lines assemble and must match.  Lines prefixed with '#' are the
# Appendix C entries the assembler does not yet implement, kept here so
# the gap is visible.  They fall into a few families:
#   - BX/DA/X/RA addressing ((hl+ix)/(nn)/(ix+dd16)/(pc+dd)) for the
#     8-bit ALU, inc/dec and byte loads
#   - DD/FD-prefixed indirect call/jp (call cc,(hl) etc.)
#   - EX A,src and EX H,L / EX IX,HL / EX IY,HL
#   - add hl,a / add ix,a, adc/sbc ix,rr, ld bc/de/sp,(mem), and the
#     word-load forms ld r,(hl+ix) etc.
#   - in/out word and block variants (indw/inirw/outdw/otirw, in ixh,(c))
#   - EPU/MEPU, EXTS, LDUD/LDUP, MULTW/DIVW, TSET (never implemented)
# Two of those silently mis-assemble rather than reject (the 16-bit-disp
# X mode parses as SX plus a stray byte, and the indirect call/jp drops
# the indirection); they are commented out pending the addressing-mode
# work, not because the manual is wrong.
